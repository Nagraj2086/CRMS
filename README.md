# CRMS — School Management System

A simple **School Management System** developed using **Python, Django, MySQL, HTML, CSS**.

The project provides CRUD operations for managing **Teachers and Students** through a clean web interface.

## 📌 Project Overview

CRMS (School Management System) is a Django-based web application designed to manage basic school information.

The system allows the user to:

* Add teachers
* View teachers
* Edit teacher information
* Delete teachers
* Add students
* View students
* Edit student information
* Delete students
* Upload teacher and student images
* Store data in a MySQL database

## 🚀 Features

### Teacher Management

* Add a new teacher
* View all teachers
* Update teacher details
* Delete teachers
* Upload teacher profile images
* Store:

  * Name
  * Subject
  * Contact
  * Email
  * Image

### Student Management

* Add a new student
* View all students
* Update student details
* Delete students
* Upload student profile images
* Store:

  * Name
  * Grade
  * Section
  * Contact
  * Image
